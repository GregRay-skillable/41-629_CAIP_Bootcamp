# 41-629_CAIP_Bootcamp

Company-maintained Skillable automation and support files related to Microsoft's
[Azure-Samples/modernize-bootcamp](https://github.com/Azure-Samples/modernize-bootcamp)
project.

## Repository structure

```text
/
├── README.md
├── skillable/
│   └── day_2/
│       └── lab04/
│           ├── lca/       # Skillable lifecycle actions
│           ├── scripts/   # Deployment helpers and supporting scripts
│           └── docs/      # Lab documentation
└── .gitignore
```

The Lab04 folders are placeholders tracked with `.gitkeep` files. No automation
scripts or CI/CD are implemented yet.

## Scope

Keep company-specific Skillable extensions and support files here. Microsoft
upstream source should not be modified directly in this repository; maintain
upstream changes in the appropriate upstream project.

Do not commit credentials, secrets, subscription IDs, tenant IDs, or
environment-specific values.
